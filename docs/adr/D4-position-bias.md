# D4 槽位交换抵消位置偏好

## 背景

判官对 A/B 槽位有偏好,同一对候选换位置可能换结论。

## 决定

- `compare`:轮次向上取整到偶数,奇数轮交换 A/B,结果还原到原始身份后求平均。
- `select`:ring 本身对称,pivot 轮的槽位由引擎逐对平衡,保留配置轮次。
- `track` 无位置偏好,保留配置轮次。
- 自动路由默认 1 轮时,按"谁更少坐 A 位"逐对定向,**不增加任何模型调用**。

## 后果

- 默认配置下 `compare` 的调用数是最小值的两倍;这是刻意付的价。
- 上游在 K≥2 时才逐次交换槽位,benchmark 默认 K=4。本仓库在 K=1 下也消除偏好,只在 K=1 时与上游不等价。
