# D7 自动路由:结构化优先,语义兜底

## 背景

Agent 准备停止时,插件需要判断"这里有值得复核的东西吗"。让模型每次自由发挥会重复付费且不可预测。

## 决定

**第一阶段(确定性,不调用模型)**只认两种对象:

- Workflow 返回的版本化候选信封(`dsh-verifier-candidates`),v2 还要求组级 `reviewStage` 与可选 `scope`;
- 同一任务内至少两个**内容或状态真实变化**的 `todo/write` 快照。

普通 Subagent 文本、裸 JSON、记账类工具输出(`todo_write` / `create_goal` / `skill` / `exit_plan_mode` 等)都不作为候选或证据。

**第二阶段(语义)**:结构化对象不足且开关打开时,让主裁判做一次严格 JSON 分类 `none / compare / select / track`。分类器只能引用本次**实际渲染出来**的 callId 或 seq;宿主再从不可变快照重建证据。

## 后果

- 两个同步的 Subagent 结果通常只是不同子任务,不会被直接当成互相竞争的候选。
- 检查点附带的是"该时刻之前最近一次成功工具输出",而不是 todo 文本——只有 todo 的检查点无法证明完成。
- 分类去重按**渲染后的提示词**而不是最后事件序号:追加纯叙述不会再次付费分类。
