# D6 固定基线与逐项阈值

## 背景

"这个会话做得不错"没有绝对刻度:只用候选之间的相对权重时,一份什么都没做的会话也能在锦标赛里排第一。

## 决定

最终验收把 Agent 的会话与一个固定的**空工作基线** `EMPTY_WORK_BASELINE` 成对比较,并同时要求:

1. `winner === 'A'`;
2. 均分不低于通过阈值;
3. **每一条判据各自**不低于阈值。

`verifier_best_of_n` 的绝对分走同一条基线与同一套判据;它的锦标赛份额是相对量,不能与阈值相比。

## 后果

- 均值不能掩盖单项彻底失败:3 条判据里 1 条 0 分、2 条满分时均分 0.67 仍会越线,逐项检查才拦得住。
- "相对最优"与"够好"是两个结论,必须分别给出。真机上出现过三份草稿全合格、锦标赛全平 0.5 的情况,那时唯一有用的信息是绝对分没过阈值。
