# D2 概率基准锦标赛按无序边去重

## 背景

N 个候选全量两两比对需要约 N(N-1)/2 场对决,调用量随候选数平方增长。

## 决定

随机 Hamilton 环上比对相邻候选,按软胜率挑出 top-k 基准,其余候选只与基准对决,再用 Bradley–Terry 建模全局排名。成本接近 O(Nk)。

环上与基准相邻的对决不在基准轮重复举行:**每个无序候选对全程只被评判一次**。

## 后果

- 胜率聚合口径与上游不同。用固定的环、pivot 与 reward 复现,上游加权下是候选 3 胜出,本地去重下是候选 0 胜出,两者都不是平局。这不是等价实现。
- `test/scoring/parity.test.ts` 把两侧的期望值分别锁住。
- 相同 seed 不保证相同环:环由随机置换构造,seed 只保证同一实现内可复现,跨语言不承诺逐位相同。
