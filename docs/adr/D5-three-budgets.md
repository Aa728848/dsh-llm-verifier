# D5 路由、验收、过程选优三本独立预算

## 背景

自动路由与最终验收都会调用裁判。早期版本共用同一个计数器。

## 决定

三本账各自计数、互不占用:

| 账 | 限制什么 | 默认 |
| --- | --- | --- |
| 路由额度 | `compare` / `select` / `track` / 语义分类 / Team 任务闸 / 计划预审 / 过程周期 | 每任务 2,每会话 8 |
| 最终验收额度 | 会话交付验收 | 每任务/每会话独立 |
| 过程周期 | 单任务购买的过程选优周期 | recovery 1,every-step 4 |

一次语义分类成立时,在**同一个预约**上原子提升为它解析出的工具,分类与执行共用一次路由额度。

路由预约时还会为至少一次最终验收预留额度:扣掉预留后放不下的一条路由会被直接拒绝。

## 后果

- 共享计数器下,路由能把最终验收的钱花光,turn 就在从未验收的情况下静默关闭。
- 一次周期里的累计预留按周期取最大值再汇总,不会把 1 → 7 记成 7 次购买。
- 每个周期在统计里留一条 `route` 观测。它是诊断口径,**不是**模型调用数。
