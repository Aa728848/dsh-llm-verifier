# D8 计划模式挂起全部自动门控

## 背景

计划模式里 Agent 的职责是调研与提案,还没有实施。此时验收必然判低分并 steering"去实际执行",等于在用户批准计划之前就命令 Agent 动手。

## 决定

折叠会话日志中最后一条 `plan/mode` 事件判定是否激活(空日志为未激活,载荷非布尔不激活)。激活期间:

- 挂起:停止边界的自动路由、Team 任务验收、最终验收,以及 pre-step 的候选早评审与过程选优登记;
- 保留:`exit_plan_mode` 的计划预审。

计划预审通过**不**标记任务完成,不设置"必须最终验收"的标记——批准计划不等于完成工作。

## 后果

- 旧宿主没有该事件时行为不变。
- 计划获批退出计划模式后,下一个停止边界照常恢复验收。
