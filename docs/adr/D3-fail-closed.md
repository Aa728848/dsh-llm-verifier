# D3 判决解析失败即关闭

## 背景

判官的输出会被解析成分数与胜者。上游 `select` 默认 `on_error="tie"`,解析失败时回落 0.5。

## 决定

- 解析不出合规判决就抛错,不给分、不放行。
- 语义路由的分类结果必须是严格 JSON;多余字段、Markdown 围栏、引用不存在或已被预算省略的证据 ID,一律拒绝。
- 判据文件的解析同样如此:没有判据、或某条判据没有正文,退回 `coding` 并在日志说明原因,不让门控失效。

## 后果

- 一次网络抖动会让这次验收失败,而不是悄悄放行。调用方需要重试或人工处理。
- 门控的可信度不依赖判官是否"听话"。
